A language encoding model is a black-box model of how the brain processes language.

The model takes a language snippet as input and outputs a prediction of how a person's brain will light up when it hears that snippet.

Language encoding models are useful tools for studying biological language processing, as they allow us to rapidly perform experiments that would be impractical in humans.

Drag a snippet into the box to see how the model predicts this person’s brain will respond.

These models are powerful, but as black boxes, they are difficult to understand.

Let's say we want to better understand how the model predicts responses in retrosplenial cortex, an area in the brain's limbic lobe.

We can learn about the model by examining its responses to a broad collection of snippets.

Some snippets will drive activations in RSC more than others. Can you notice any patterns?

All of the top snippets mention locations.

An LLM can recognize these kinds of patterns too.

This gives us an automated method for generating candidate explanations for areas like RSC.

We can use these candidate explanations to generate driving stimuli to test in vivo.

This gives us a causal feedback mechanism to evaluate the semantic hypotheses generated by encoding models.

In our newest paper, we use this method, Generative Causal Testing, to drive activity in targeted areas across cortex.

Generative causal testing to bridge data-driven models and scientific theories in language neuroscience
